# 2026-10-15 end-to-end acceptance / 端到端验收

**13 packages passed on the recorded development build. Things 3 was skipped and is not included.**

Environment: macOS 27.0.1, Apple silicon, TextEdit, Google Chrome. Bubboo reports 0.1.1 build 2, but this is a development build with changes after the published 0.1.1 release. Exact executable SHA-256: `ded4e0a5432a8ebb0d6ea2e97ebbb5fe4cb79688c2d20ff95f62c728eb3b149c`.

**No minimum released Bubboo version has been established.** `minimumBubbooVersion: null` is intentional. These prerelease downloads target this development build, not a blanket compatibility promise for the public 0.1.1 application. A stable extension release requires acceptance against a publicly available App build.

## Method

Each package was imported/enabled through Bubboo Settings. With explicit user authorization, macOS Accessibility automation activated a synthetic TextEdit document, selected text using real keyboard input, and pressed the actual Bubboo toolbar button. Results were read back from TextEdit or the browser actually opened by the action. Browser destination titles/fields and translation output were inspected. No test called the extension action directly in place of a toolbar click. Independent Store/helper tests supplement, rather than replace, this evidence.

All four Settings selections were restored to their defaults after verification. Toolbar text icons were visually checked. Things 3 is intentionally excluded: required application unavailable.
